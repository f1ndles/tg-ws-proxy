# Changelog

## v23 (2026-08-11)

### Новое
- **Default Domains** — автоматическая загрузка списка рабочих CF доменов с GitHub при старте (`--default-domains`). Не требует настройки своего домена
- **CF Priority** — CF прокси теперь пробуется **до** прямого WS подключения (`--cf-priority`), что ускоряет подключение в заблокированных сетях
- **CF Balance** — балансировка подключений между несколькими CF доменами по round-robin (`--cf-balance`)
- **Поддержка DC203** — медиа-датацентр теперь корректно передаётся через `--dc-ip 203:IP`
- **WebUI** — добавлены поля Default Domains, CF Priority, CF Balance в интерфейс настроек
- **DC IP** — добавлено поле для ручной настройки IP датацентров прямо из WebUI

### Исправлено
- Исправлен баг с передачей DC_IP на Android sh — цикл через `tr ',' ' '` вместо IFS loop, который обрезал последний элемент
- Добавлен `setprop net.dns1/dns2` перед запуском для корректного DNS резолвинга
- Исправлена логика сохранения конфига при обновлении модуля
